# Tabledown XML 형식 스펙 v2 — 다단 헤더 중첩 (방안1: 일반 태그)

> 확정: 2026-06-08 · `copy_as_xml` / `model_to_xml` 가 생성하는 형식.
> 기존 v1(`<dataset><row><cell name>`)을 대체. 사용자 확정 형식.

## 1. 목표
다단 헤더(가로·세로 양방향 그룹)를 XML **중첩 계층**으로 보존한다. **flatten 금지.**
상위 그룹 = 부모 노드, 하위 항목 = 자식 노드. 이름표 = 속성(attribute), 셀 값 = 리프 텍스트.

## 2. 태그 / 속성 매핑

| 표 요소 | 태그 | 속성 | 텍스트 |
|---------|------|------|--------|
| 루트 | `<표>` | — | — |
| 세로 상위그룹 | `<{헤더}그룹>` | `이름="값"` | — |
| 행 (세로 최하위) | `<행>` | `{헤더}="값"` | — |
| 가로 상위그룹 | `<열그룹>` | `이름="값"` | — |
| 가로 리프(셀) | `<열>` | `n="헤더값"` | 셀 값 |

- 루트가 `<표>`(한글)인 이유: `<table>`(영문)은 HTML 요소라 브라우저/Obsidian 미리보기/리치에디터가 table 규칙을 적용해 비-table 자식을 밖으로 밀어내(foster-parenting) 내용을 비운다. 한글 `표`/`행`/`열`/`열그룹`은 HTML 요소가 아니라 안전 — v1이 `<dataset>`을 쓴 것과 같은 이유.
- 가로축 태그(`열그룹`/`열`)는 **고정 일반 태그**, 헤더는 속성값(`이름`/`n`)으로 → 헤더에 공백·기호·숫자·중복이 있어도 안전(속성값은 escape만 하면 무엇이든 OK). 가로 차원 이름(`분기`,`월`)은 표에 없으므로 만들지 않는다(방안1).

## 3. 변환 알고리즘 (표 → XML)

입력: `model = (header_rows, data_rows)` — `header_rows`는 가로 헤더의 각 단(병합 채움 완료), `data_rows`는 세로 rowspan forward-fill된 데이터(좌측 키 열 포함). `_build_columns`로 컬럼 트리를 만든다(기존 함수 재사용).

1. **세로 키 열 식별** = 컬럼 트리 top-level에서 **왼쪽부터 연속된 leaf** 중, **첫 `group`(가로 계층) 앞**까지, **헤더가 유효 XML 이름인 것**.
   - 가로 `group`이 하나도 없으면(= 단순 표) **세로 키 = 0개** → 모든 열이 데이터.
   - 헤더가 XML 이름 규칙 위반(공백·기호·숫자시작·`xml` 접두)인 열을 만나면 거기서 세로 키 종료(그 열부터 데이터). → **정규화 불필요, 무손실 roundtrip 유지.**
2. **세로 키 K개로 행 계층 구성**:
   - `K ≥ 2`: 앞 `K-1`개 헤더 → 중첩 그룹 `<{헤더_i}그룹 이름="값">` (인접 행의 동일 그룹값을 연속 런으로 묶음, 다단계 중첩). 마지막 헤더 → `<행 {헤더_K}="값">`.
   - `K == 1`: `<행 {헤더}="값">` (세로 그룹 없음).
   - `K == 0`: `<행>` (행 식별 키 없음).
3. **각 행 내부 = 데이터 열의 가로 컬럼 트리**:
   - `group` → `<열그룹 이름="값">` (다단계 중첩)
   - `leaf` → `<열 n="leaf헤더값">셀값</열>`  (값은 `<br>`→줄바꿈, XML escape)
4. 전체를 `<표>…</표>`로 감싼다.

## 4. 예시

### 4-1. 교차표 (사용자 확정 케이스)
입력: 가로 2단(1분기▸1,2,3 / 2분기▸4,5,6), 세로 2단(직급▸부장/차장, 직책).

```xml
<표>
  <직급그룹 이름="부장">
    <행 직책="대족장">
      <열그룹 이름="1분기"><열 n="1">동</열><열 n="2">해</열><열 n="3">물</열></열그룹>
      <열그룹 이름="2분기"><열 n="4">과</열><열 n="5">백</열><열 n="6">두</열></열그룹>
    </행>
    <행 직책="족장"> … </행>
    <행 직책="추장"> … </행>
  </직급그룹>
  <직급그룹 이름="차장"> … 5개 행 … </직급그룹>
</표>
```

### 4-2. 단순 표 (가로 group 없음 → 세로 키 0)
입력: `| name | val |` / `| A | 1 |`

```xml
<표>
  <행>
    <열 n="name">A</열>
    <열 n="val">1</열>
  </행>
</표>
```

### 4-3. 세로 1단만 (가로 group 있음, 좌측 키 1열)
```xml
<표>
  <행 항목="매출">
    <열그룹 이름="2024"><열 n="Q1">…</열></열그룹>
  </행>
</표>
```

## 5. 역변환 (XML → model) · roundtrip
- `<직급그룹>` 태그에서 접미사 `그룹`을 떼 세로 상위 헤더 복원, `이름=` 으로 그룹 값.
- `<행 직책="…">` 의 속성 key로 세로 최하위 헤더, 값으로 행 키.
- `<열그룹 이름>`/`<열 n>` 로 가로 헤더 단 복원, `<열>` 텍스트로 셀 값.
- 세로 키 헤더가 항상 유효 XML 이름이도록 §3-1에서 보장 → 태그/속성에서 헤더를 손실 없이 복원.

## 6. is_table_xml 가드 (false-positive 차단 — 불변식 5 유지)
보수적으로: 다음을 모두 만족할 때만 표 XML로 인정.
- 루트의 직접 자식이 모두 `행` 또는 `{X}그룹`(재귀적으로 `행`을 포함).
- `행`의 자식은 `열` 또는 `열그룹`(재귀)만. `열`은 leaf(자식 없음).
- `행`이 2개 이상 **또는** 루트가 알려진 표 루트(`표`,`dataset`,`table`…)·행 태그가 알려진 것.
- config/문서/임의 XML 은 거부. **이 가드를 느슨하게 풀지 말 것.**

## 7. 트레이드오프 (의도된 변경)
- **세로 중첩 ⇒ 행이 자기완결이 아님**: 직급이 부모(`<직급그룹>`)에만 있어, 행 하나만 떼면 직급을 모른다. v1은 일부러 매 행에 직급을 반복(자기완결 레코드)했다. 사용자 확정 형식은 계층 보존을 우선해 이 자기완결성을 포기한다.
- **마크다운 경로는 무관**: 마크다운은 병합/계층 표현 불가라 기존대로 평면 결합 헤더(`_combine_header_levels`) 유지.
